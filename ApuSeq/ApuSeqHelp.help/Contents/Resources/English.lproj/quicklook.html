Quick Look previews

Preview files in Finder

Select a supported alignment file in Finder and press Space to preview it with Quick Look.

Preview behavior

Quick Look uses a compact preview with residue coloring and limits the amount of text shown so that previews remain responsive.

If another preview appears

macOS chooses a Quick Look extension based on registered file types and installed apps. Keeping ApuSeq in the Applications folder and rebuilding the Quick Look cache can help when Finder continues using another preview provider.
