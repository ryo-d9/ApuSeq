ApuSeq Help

Editing alignments

Edit mode

Edit mode uses the macOS document model, including autosave and versions. Use File > Revert To to browse previous versions when available.

Alignment length

When text is inserted or deleted, ApuSeq keeps sequences aligned by adding gap characters to the affected columns as needed.

Adding and renaming sequences

In Edit mode, choose Edit > Add Sequence or Control-click the sequence name area and choose Add Sequence. ApuSeq adds a gap-filled row that can be edited directly in the alignment view.

To rename a sequence, Control-click or right-click its name and choose Rename Sequence.

Sequence deletion

In Edit mode, Control-click or right-click a sequence name and choose Delete Sequence. If the deleted sequence is the reference, the reference selection is cleared.

Remove all-gap columns

Edit > Remove All-Gap Columns removes columns where every sequence contains a gap. Both - and . are treated as gaps. The command is undoable and is disabled when it would leave the alignment empty.

Reverse complement

Edit > Reverse Complement creates a new unsaved FASTA document from the reverse complement of each nucleotide sequence. The original document is not changed.

ApuSeq preserves lowercase residues as lowercase. Ambiguous nucleotide codes are complemented when possible, and gap characters remain in place after the sequence order is reversed.

MAFFT alignment

Edit > Align with MAFFT Auto creates a new unsaved FASTA document aligned by the bundled MAFFT executable using its automatic strategy selection.

The original document is not changed. While MAFFT is running, ApuSeq shows a progress sheet with a Cancel button.
