ApuSeq Help

Editing alignments

Edit mode

Edit mode uses the macOS document model, including autosave and versions. Use File > Revert To to browse previous versions when available.

Alignment length

When text is inserted or deleted, ApuSeq keeps sequences aligned by adding gap characters to the affected columns as needed.

Sequence deletion

In Edit mode, Control-click or right-click a sequence name and choose Delete Sequence. If the deleted sequence is the reference, the reference selection is cleared.

Remove all-gap columns

Edit > Remove All-Gap Columns removes columns where every sequence contains a gap. Both - and . are treated as gaps. The command is undoable and is disabled when it would leave the alignment empty.
