ApuSeq Help

Editing alignments

Edit mode

Edit mode can modify the contents and uses a system feature to autosave. Use File > Revert To to browse previous versions when available.

Commands that change sequence names or named sequence order are available for FASTA, CLUSTAL, CLUSTAL W, and MUSCLE documents.

Very large alignments are best edited in small steps because each edit may take longer to update the document view.

Alignment length

Typing and deletion in the alignment viewport edit only the selected sequence rows. ApuSeq pads shorter rows with trailing - characters so the alignment remains rectangular.

Choose Edit > Insert Gap Column, or press ⌘ ⇧ - to insert a gap column at the current cursor position across all sequences.

Remove all-gap columns

Alignment > Remove All-Gap Columns removes columns where every sequence contains a gap. Both - and . are treated as gaps. The command is undoable and is disabled when it would leave the alignment empty.

Trim trailing gaps

Alignment > Trim Trailing Gaps removes trailing - and . characters from each sequence in Edit mode. ApuSeq may still display temporary padding gaps after trimming to keep alignment columns visually aligned.

Adding and renaming sequences

In Edit mode, choose Edit > Add Sequence or Control-click the sequence name area and choose Add Sequence. ApuSeq adds a gap-filled row that can be edited directly in the alignment view.

Choose Edit > Add FASTA from Clipboard, or press ⌘ ⇧ V to append FASTA records from the clipboard. Multi-line FASTA sequences are supported.

In a new empty document, Add Sequence or Add FASTA from Clipboard starts a FASTA alignment.

To rename a sequence, select it and choose Alignment > Current Sequence > Rename Current Sequence, or Control-click its name and choose Rename Sequence.

Sequence deletion

In Edit mode, select a sequence and choose Alignment > Current Sequence > Delete Current Sequence, or Control-click its name and choose Delete Sequence. Delete Sequence is available when the alignment contains two or more sequences. If the deleted sequence is the reference, the reference selection is cleared.

Finding sequence names

Choose Edit > Find Sequence Name, or press ⌘ ⇧ F, to show the search field above the sequence name column.

The search field updates matching sequence names as you type. Press Return to move to the next match, Shift-Return to move to the previous match, or Escape to close the field and clear the highlighted sequence name.

Sort sequences

Alignment > Sort Sequences reorders the document contents by sequence name or UPGMA in Edit mode. UPGMA sorting is available for alignments with 3 to 300 sequences.

Use View > Display Order to change only the displayed order without modifying the document.

Reverse complement

Alignment > Reverse Complement creates a new unsaved FASTA document from the reverse complement of each nucleotide sequence.

ApuSeq preserves lowercase residues as lowercase. Ambiguous nucleotide codes are complemented when possible, and gap characters remain in place after the sequence order is reversed.

Translation

Alignment > Translation creates a new unsaved FASTA document translated from nucleotide sequences in frame +0, +1, or +2.

The codon table is selected in Settings > General > Translation.

MAFFT alignment

Alignment > Align with MAFFT > Entire Alignment creates a new unsaved FASTA document aligned by the bundled MAFFT executable using the mafft --auto command.

While MAFFT is running, ApuSeq shows a progress sheet with a Cancel button.

In Edit mode, select one or more columns and choose Alignment > Align with MAFFT > Selected Columns to realign only those columns across all sequences. ApuSeq removes gaps from the selected region before sending it to MAFFT, then restores the aligned region between the unchanged prefix and suffix columns. The command is undoable and leaves the document unchanged if alignment fails.

For coding nucleotide FASTA files, choose Alignment > Align with MAFFT > Amino-Acid-Guided Nucleotide Alignment, then select frame +0, +1, or +2. ApuSeq translates each sequence, aligns the amino acid sequences with MAFFT, and maps the result back to nucleotide codons. The command creates a new unsaved FASTA document and requires at least two nucleotide sequences with complete codons in the selected frame.
