Viewing alignments

View mode

View mode is optimized for fast navigation and does not modify the file.

Panels

Reference, Consensus, and Identity panels can be shown from the View menu.

Reference
Shows the selected reference sequence while keeping it in the main alignment display.
Consensus
Shows the majority residue at each site.
Identity
Shows per-column identity using the selected threshold.

Coloring and order

Use the footer controls or the View menu to change background coloring and display order.

View > Background Color offers None, Residue, Different, and Identity modes. None shows the alignment without residue background coloring.

View > Display Order offers Original, Name, and UPGMA. Original follows the file, Name sorts by sequence name, and UPGMA is a view-only clustering order for alignments with 3 to 300 sequences. Display order changes do not modify the file and are disabled in Edit mode.

Status bar

The status bar summarizes the visible document, for example Sequences: 12 (1) Sites: 1240 (42) Columns: 120-161.
