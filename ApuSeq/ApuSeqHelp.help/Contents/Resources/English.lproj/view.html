Viewing alignments

View mode

View mode is optimized for fast navigation and does not modify the file.

Very large alignments may scroll more slowly with per-residue coloring. Switch Background Color to None when you need the fastest navigation.

Panels

Reference, Consensus, and Identity panels can be shown from the View menu.

Reference
Shows the reference sequence. The reference can be selected by right-clicking the name of the sequence, and is kept in the main alignment display.
Consensus
Shows the majority residue at each site.
Identity
Shows per-column identity using the selected threshold.

Identity threshold can be adjusted in Settings > General > Identity Threshold.

Coloring

Use the footer controls or the View menu to change background coloring and display order.

View > Background Color offers None, Residue, Minority, Reference, and Identity modes.

Residue
Colors all residues by type.
Minority
Colors residues by type that differ from the majority residue.
Reference
Colors residues that differ from the selected reference sequence.
Identity
Colors columns using the selected identity threshold.

Display order

View > Display Order offers Original, Name, and UPGMA.

Original
Follows the sequence order in the original file.
Name
Sorts by sequence name.
UPGMA
View-only clustering order for alignments with 3 to 300 sequences.

Status bar

The status bar summarizes the visible document, for example Sequences: 12 (1) Sites: 1240 (42) Columns: 120-161. The number in the parentheses indicates the number of selected sequences or sites.

Inspector

Click the information button in the toolbar to show document, selection, and view information, including format, sequence kind, selected columns, reference sequence, display order, and background coloring.

Copying sequences

Control-click or right-click a sequence name and choose Copy Sequence to copy only the sequence text, or Copy as FASTA to copy the sequence name and sequence in FASTA format.

Consensus sequences can be copied using Edit > Copy Consensus.

Additional sequence operations

Translation, Reverse Complement, and MAFFT alignment are available in both View and Edit modes. For more information, see Editing Alignments.
