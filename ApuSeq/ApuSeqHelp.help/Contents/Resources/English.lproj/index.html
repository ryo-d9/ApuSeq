ApuSeq Help

Sequence alignment viewer and editor for macOS.

It supports FASTA, CLUSTAL, CLUSTAL W, MUSCLE, and plain-text alignment files.

View alignments

View mode keeps the file unchanged while you inspect coloring, panels, and display order.

  • How to view alignments

Edit alignments

Edit mode enables document-changing commands such as trimming gaps and sorting sequences, with undo support.

  • How to edit alignments

Quick Look previews

Preview supported alignment files in Finder with Quick Look.

  • How to use Quick Look previews
