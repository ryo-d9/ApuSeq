ApuSeq Help

ApuSeq is a lightweight native macOS viewer and editor for sequence alignments.

  • Viewing alignments
  • Editing alignments
  • Quick Look previews

Supported files

ApuSeq opens FASTA, CLUSTAL, CLUSTAL W, MUSCLE, and plain-text alignment files.

View and Edit modes

View mode keeps the file unchanged while you inspect coloring, panels, and display order. Edit mode enables document-changing commands such as trimming gaps and sorting sequences, with undo support through the macOS document model.

MAFFT alignment

Choose Alignment > Align with MAFFT Auto to create a new FASTA document aligned by the bundled MAFFT executable. The source document is not changed.

Open source licenses

Choose Help > Open Source Licenses to view notices for bundled third-party components, including MAFFT.
