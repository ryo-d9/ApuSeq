ApuSeq Help

for macOS

Work with sequence alignments

ApuSeq is a lightweight, fast viewer and editor for multiple sequence alignments. Open FASTA, CLUSTAL, CLUSTAL W, MUSCLE, and plain-text alignment files, then inspect or edit sequences in a native macOS interface.

Explore alignments at a glance

View mode keeps the file unchanged while you inspect coloring, panels, and display order.

Refine alignments with flexible editing

Edit mode enables document-changing commands such as trimming gaps and sorting sequences, with undo support.
