# Changelog

## Unreleased

### Added
- Integrated open source license notices into the About ApuSeq window.
- Localized Quick Look truncation messages in Japanese.

### Changed
- Improved Japanese localization across app menus, settings, dialogs, Help Book, and Quick Look.
- Updated inspector command localization and shortcut behavior.
- Refined terminology for sequence, alignment, genetic code, display order, and edit-mode warnings.

## 1.2.0 - 2026-08-24

### Added
- Added alignment printing.
- Added print font size setting.
- Added Help Book documentation for printing.

### Changed
- Made printing respect visible alignment panels.

## 1.1.0 - 2026-08-12

### Added
- Added sequence editing commands, including adding, deleting, renaming, sorting, and gap editing.
- Added sequence name search and navigation tools.
- Added reference, consensus, and identity panels with keyboard shortcuts.
- Added translation, reverse complement, and MAFFT-based alignment workflows.
- Added codon alignment for coding nucleotide FASTA files.

### Changed
- Improved alignment viewport layout, clipping, ruler sizing, and name column behavior.
- Improved disabled states for alignment menu commands.
- Hardened alignment parsing and Quick Look preview handling.

## 1.0.0 - 2026-08-06

### Added
- Initial release of ApuSeq as a lightweight macOS alignment viewer.
- Added support for FASTA, CLUSTAL, MUSCLE-style, and plain-text sequence files.
- Added Quick Look preview support for sequence alignment files.
